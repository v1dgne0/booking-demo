# Routes

## `/` — Home page

- Entry: `index.html`
- Layout: one static document with header, main content, and footer.
- Sections: hero `#top`, services `#services`, team `#team`, portfolio illustrations `#works`, booking `#booking`, and contacts `#contacts`.
- Overlay: client profile and local booking history in `dialog#profile-dialog`.
- Styles: `styles.css`
- Interactions and data: `script.js`
- Assets: `assets/hero.png`, `assets/logo.svg`

There is no client-side router; navigation uses in-page anchors.
