# Демо-сайты для салонов

Каждый адрес в этой папке — отдельный самодостаточный сайт. Новые демо создаются на основе `yagoda-copy/`, с отдельной палитрой, фирменной графикой и содержанием под конкретную студию.

## Концепты

- `bocha-home/` — Bocha Home
- `vtope/` — ВТОПЕ
- `blik/` — Blik
- `koko/` — KOKO
- `lokon/` — LOKON

`index.html` — короткий каталог этих пяти демо для GitHub Pages. Публикационный workflow собирает только эти пять каталогов и каталог-страницу.

Цены, профили, отзывы, контакты, график и запись обозначаются как демонстрационные, если пользователь не предоставил проверенные данные. Все сайты сохраняют заявки только в `localStorage` текущего браузера; они не связаны с салонами.
