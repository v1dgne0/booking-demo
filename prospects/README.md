# Демо-сайты для салонов

Каждый адрес в этой папке — отдельный самодостаточный сайт. Новые демо создаются на основе `yagoda-copy/`, с отдельной палитрой, фирменной графикой и содержанием под конкретную студию.

## Концепты

- `bocha-home/` — Bocha Home
- `vtope/` — ВТОПЕ
- `blik/` — Blik
- `koko/` — KOKO
- `lokon/` — LOKON

`index.html` — каталог первой серии. GitHub Pages публикует содержимое ветки `main` встроенной сборкой Pages; отдельный workflow в `.github/` не требуется.

Цены, профили, отзывы, контакты, график и запись обозначаются как демонстрационные, если пользователь не предоставил проверенные данные. Все сайты сохраняют заявки только в `localStorage` текущего браузера; они не связаны с салонами.

## Webdemos 1

Отдельная серия по референсам пользователя: [каталог пяти демо](webdemos-1.html).

- `mvz-friends/` — Mvz Friends, графит и фуксия
- `voskhishchenie/` — Восхищение, пудровый и розово-лиловый
- `brusnika/` — BRUSNIKA, бордо и светлый кремовый
- `tvoe-zhelanie/` — Твое желание, синий и серебристый
- `luna/` — ЛуНа, лунный свет и бирюзовый

Каждая папка сначала целиком скопирована из `yagoda-copy/`. Для каждого демо отдельно сгенерировано изображение маникюра. Прайсы и контакты не предоставлены, поэтому все услуги, цены и расписание условные. Публичный каталог: [https://v1dgne0.github.io/booking-demo/prospects/webdemos-1.html](https://v1dgne0.github.io/booking-demo/prospects/webdemos-1.html). Новые демо добавляйте в каталог с сохранением существующих карточек и самодостаточных папок.
