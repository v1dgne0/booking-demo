# Проверка Webdemos 1

Проведено 30 октября 2026 года в браузере Chromium через локальный HTTP-сервер. Это фактически выполненные проверки, не перенос утверждений из README шаблона.

Для каждой из пяти папок проверены:

- Широкий экран 1440 × 1000, мобильный 390 × 844 и узкий 320 × 740. Нет горизонтального переполнения, сломанных изображений и элементов, выходящих за ширину. Отдельные финальные мобильные снимки сделаны при 390 × 1100, чтобы показать изображение целиком.
- Мобильное меню: открытие, переход к услугам с закрытием меню, закрытие по Escape.
- Пустой профиль, возврат фокуса после Escape, карточка мастера без отзывов, палитра из 16 оттенков.
- Клавиатура: Tab, выбор услуги стрелками и Enter, видимый фокус 3 px.
- Запись: отсутствие даты и времени вызывает ошибки; месяц переключается; недоступные даты и занятый слот заблокированы; после выбора свободного слота работают ошибки имени/телефона и согласие с условиями.
- Успешное сохранение с тестовым именем «Тест Демо» и вымышленным номером, появление в профиле, запрос подтверждения отмены и удаление записи.
- Отзыв после прошедшего визита: временная локальная тестовая страница создала прошедший визит, затем через обычный интерфейс сохранён отзыв мастеру с оценкой 4; текст появился в карточке Миры, рейтинг стал 4.0.
- Повреждённый JSON в отдельных ключах нового демо обрабатывается как пустое хранилище. Тестовые данные удалены, временная страница проверки удалена из проекта.
- В консоли проверяемых страниц не обнаружено предупреждений или ошибок приложения.

Контраст рассчитан для текстовых токенов на фактических сплошных фонах: обычные подписи, кнопки, выбранные/отключённые даты, списки и бейджи. Минимальные отношения по палитрам: Mvz Friends — 4.62:1, Восхищение — 4.53:1, Brusnika — 4.63:1, Твое желание — 4.76:1, ЛуНа — 4.68:1. Для фотографий подписи имеют непрозрачную светлую подложку. Подписи тёмных первых экранов используют отдельные светлые токены.

Правило `prefers-reduced-motion` проверено в исходных CSS: глобальные анимации/переходы сокращаются, плавная прокрутка отключается, скрытие раскрываемых элементов снимается. В сценариях JS используется проверка `matchMedia`. Переключение системной настройки ОС отдельно не выполнялось.

Статическая проверка: все локальные ссылки и ресурсы разрешаются, ID не повторяются, ссылки на разделы корректны, локальные шрифты на месте. Число функций JS совпадает с `yagoda-copy`: сценарии основы сохранены; изменены ключи хранения и брендовые строки.

Артефакты: `qa/results.json`, `qa/reviews-and-storage.json`, `qa/layouts.json`, `qa/contrast-tokens.json`, `qa/static.json`, широкие и мобильные JPEG. `qa/overview.jpg` — обзор пяти вариантов.
