# KOKO — концепт сайта

Самостоятельная демонстрационная версия сайта для обсуждения визуальной подачи. Сборка основана на шаблоне `yagoda-copy`, а содержание, палитра и фирменная графика адаптированы под KOKO.

## Данные и ограничения

- Это концепт и не официальный сайт студии.
- Имена, профили мастеров, отзывы, адрес, график, занятость и портфолио условные.
- Для Bocha Home цены перенесены с предоставленного изображения прайса; для ВТОПЕ отображены пять выбранных услуг и цены из референса. В остальных концептах цены взяты из демо-шаблона и не выдаются за актуальный прайс.
- Запись, профиль и отзывы сохраняются только в `localStorage` текущего браузера. Данные не отправляются в салон и не видны другим посетителям.
- Иллюстрации работ нарисованы CSS и не представляют реальные работы мастеров.

Откройте `index.html` или запустите из папки демо `python3 -m http.server 8000`.
