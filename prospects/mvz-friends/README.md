# Mvz Friends — демо, webdemos 1

Каталог скопирован целиком из `yagoda-copy/`, после чего изменены бренд, тексты, дизайн-токены, декоративные стили и изображения. Сценарии записи, календарь, профили и отзывы сохранены из основы. Папка самодостаточна, внешних пакетов нет.

Это не официальный сайт. Название и фирменная графика взяты из пользовательского референса. Цены, услуги, мастера, отзывы и расписание — условные; подтверждённые адрес и контакты не предоставлены. Заявки никуда не отправляются. Хранение только в localStorage этого браузера, отдельный префикс `mvz-friends:`.

Первый экран: `assets/hero-800.webp`, `assets/hero-1200.webp` и JPEG-версии. Изображение создано встроенным Imagegen, это не фотография реальной работы салона. Фирменная графика: `assets/brand-reference.webp`. Портфолио — CSS-иллюстрации. Полные промпты: [image-prompts.md](../webdemos-1/image-prompts.md).

Запуск из корня репозитория: `python3 -m http.server 8000`, затем `/prospects/mvz-friends/`. Статус фактических проверок указан в [QA.md](../webdemos-1/QA.md).
