# Repository Guidelines

## Проект и структура

Это статический одностраничный сайт вымышленной маникюрной студии «Ягода». `index.html` содержит семантическую разметку и тексты, `styles.css` — адаптивное оформление, `script.js` — каталог услуг и интерактивность демо-записи, `assets/hero.png` — сгенерированная иллюстрация первого экрана. Внешние пакеты, сборщик и тестовый фреймворк не используются. Портфолио нарисовано CSS-иллюстрациями; не добавляйте их как реальные фотографии работ.

## Запуск и проверка

Откройте `index.html` в актуальном браузере. Для локального HTTP-сервера без установки зависимостей можно выполнить из корня:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Проверьте вручную ширину телефона и компьютера, клавиатурную навигацию, смену услуги/мастера, отсутствие слотов, телефон и успешное подтверждение. В проекте пока нет автоматических тестов или команд сборки.

## Стиль и изменения

Сохраняйте русский язык интерфейса, семантические HTML-элементы, видимый фокус и мобильную доступность. Используйте два пробела для отступов в HTML, CSS и JavaScript; имена CSS-классов пишите в kebab-case, переменные и функции JavaScript — в camelCase. Общие стили и цвета задавайте через токены в `:root`; не добавляйте зависимость ради простого эффекта.

Все цены, имена, расписание, адрес и контакты являются условными. Ясно обозначайте демо-данные; запись хранится только в `localStorage` текущего браузера и не отправляется студии. Не представляйте этот сценарий как рабочую запись клиента.

## Коммиты и pull request

В доступной Git-истории нет образцов, поэтому это рекомендация, а не установленная конвенция: используйте короткий глагольный заголовок на русском, например `Добавить выбор времени`. В PR опишите пользовательское изменение и ручные проверки; для визуальных правок приложите скриншот мобильного и широкого экранов. Не включайте клиентские данные или секреты.
