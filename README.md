# Ягода — студия маникюра

Портфолио-проект одностраничного сайта с демонстрационным сценарием онлайн-записи. Все цены, специалисты, портфолио, расписание, адрес и контакты условные. Подтверждение сохраняется только в локальном хранилище текущего браузера; заявка в студию не отправляется.

## Запуск

Можно открыть `index.html` напрямую или запустить локальный сервер из папки проекта:

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для настоящего приёма заявок понадобятся серверное API, общее хранилище расписания, защита персональных данных и подключение к процессу студии.
